# Authoring guide — `general/resources/index.md`

**Purpose.** A curated **index of external references** the project keeps needing — docs, dashboards,
tickets, repos, design links. Pointers, not content.
**Write / update.** Seed with whatever surfaced during onboarding; add an entry whenever a genuinely
reusable reference is gathered.
**Length.** A link list. If you're pasting content, it belongs in the referenced place, not here.

## Structure
Grouped links under short category headings. Each entry: **label — URL/location — one-line why.**

## Template
```markdown
# Resources

## Docs
- <label> — <url> — <why it matters>

## Dashboards & tickets
- <label> — <url> — <why>

## References
- <label> — <url or path> — <why>
```

## Rules
- **Index, don't archive** — a link + a one-line reason, never the referenced material itself.
- **Only durable, reusable refs** — not one-off links from a single task.
- **No frontmatter.**
