# Universal constitution (learned, always-on)

Learned **operational** constitution — behavior-governing declarative content (rules, conventions,
character) produced by the self-learning loop (`capture → distill → ratify → write → publish`) and
**assembled into the system prompt every turn** for the active scope × mode.

- `dev/` — universal dev-mode constitution · `core/` — universal core-mode constitution.
- **One file per item** (frontmatter carries `enabled`); the owner can enable / disable / delete each.
- This is the **universal** home (applies in every repo). Per-repo constitution lives at
  `superme_agent/local-harness/<id>/<mode>/constitution/`.
- The hand-authored `SELF.md` + `{core,dev}-charter.md` are **never auto-written** — learned
  items live here, kept separate.

See `general_docs/learning-workflow-spec.md`. This dir is operational, so it lives **with the code**
(committed), unlike knowledge (`superme-knowledge/`, gitignored).
